# Только веб, без нативных приложений

Четыре поверхности (админ, врач, публичная запись, кабинет пациента) делаем одним адаптивным веб-приложением. Клиент записывается по ссылке или QR без установки, врач открывает сайт на телефоне. Нативные приложения не окупают стоимости двух магазинов и сопровождения для MVP; при необходимости позже добавим PWA.
