# Один общий Postgres с изоляцией Clinic через row-level security

Все Clinic живут в одной базе, каждая таблица имеет `tenant_id`, изоляцию обеспечивает RLS в PostgreSQL, а не только фильтры в коде приложения. Альтернативы (база или схема на Clinic) дороже в обслуживании при сотнях небольших клиник. Утечка данных между Clinic недопустима, поэтому защита стоит на уровне БД, и на изоляцию обязательны интеграционные тесты.
